# AI Usage

During development, AI tools were used to accelerate research, structure the implementation plan, and improve the clarity of the rule descriptions.

## What was used
- AI-assisted legal research for the EU AI Act and related transparency and governance topics.
- AI-assisted code review suggestions for rule logic and UI wording.
- AI-assisted drafting support for the project documentation and prompt structure.

## How it was used
- To locate relevant references and compare candidate rule formulations.
- To draft explanatory text for the questionnaire and result views.
- To review the consistency of the rule categories and the LLM prompt boundaries.

## What was verified manually
- All legal interpretations were checked against official EU sources and adapted where needed.
- The deterministic rule engine was kept authoritative; the LLM was treated as an explanatory layer only.
- The final implementation and tests were reviewed manually before being accepted.
